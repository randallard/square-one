## Gaps and proposed fixes
Nothing here has been applied. Smallest first:

1. **Lint gate:** add `"@typescript-eslint/switch-exhaustiveness-check": "error"` to
   `eslint.config.js`, and `--max-warnings 0` to the `lint` script.
2. **pnpm explicit settings (ADR-1016):** add `trustPolicy: no-downgrade`, `blockExoticSubdeps: true`
   and an empty `allowBuilds`/`onlyBuiltDependencies` to `pnpm-workspace.yaml`.
3. **CI timeouts (ADR-1005):** `timeout-minutes: 15` on every job (30 on the Kani job, which never
   runs here), as the template's `ci.yml`; check `docs-hygiene.yml` and `stance-review.yml` too.
4. **Secret scan:** copy the template's `secret-scan` job (gitleaks 8.30.1, checksum-verified) and
   add it to `deploy`'s `needs`. `.env.example`: either add an empty one or record in an ADR that
   the library reads no environment.
5. **Node 24 (ADR-1013):** `node-version: 24` in both TS jobs, `"engines": { "node": ">=24" }`.
   Consumers (the-lot) should be checked first.
6. **Exact pins:** strip `^`/`~` from devDependencies to the locked versions.
7. **ADR-1012 answers:** ask Ryan the three questions (strictness extras, an `any` registry, a11y
   lint) and record a project ADR; a11y is "no, library".
8. **TypeScript 6.0.x (ADR-1010):** bump `typescript` to 6.0.x and fix what the compiler finds;
   biggest of the code changes.
9. **Inherited ADRs + conventions skill:** copy `docs/adr/1000–1017` and the template's
   `project-conventions/SKILL.md` in, then reconcile any 1NNN this repo deviates from with a 0NNN
   (ADR-1000). Fixes 1–8 are most of what they'd ask.
10. **Stance review:** run the `stance-review` skill once the above lands.
